# Hack-Club-Website

My first HTML webpage, designed to look like an OS.
Quite basic, but it works.
Minor AI use to fix one bug.

It features a notes app, along with an app where you can write a to-do list. It can have all 3 apps open at once, and you can close and open the apps as you please. It also has a bar at the top where you can open the welcome screen app and also shows the current date and time.
